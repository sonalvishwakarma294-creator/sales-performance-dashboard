# Sales Report Dashboard

## Overview

The Sales Report Dashboard is an interactive Power BI project developed to analyze sales performance and provide actionable business insights. It enables users to monitor key performance indicators (KPIs), track revenue and profit trends, evaluate product performance, and explore sales data through interactive visualizations.

## Features

- Interactive dashboard with dynamic filters
- Sales, Revenue, and Profit analysis
- Product and Category performance
- Regional sales insights
- Key Performance Indicators (KPIs)
- Interactive charts and visualizations

## Technologies Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## How to Use

1. Download or clone this repository.
2. Open the `Sales_Report.pbix` file using Microsoft Power BI Desktop.
3. Load the dataset if prompted.
4. Refresh the data and explore the interactive dashboard.
